A high-performance proxy for LLM inference APIs. It meters tokens,
enforces token-based rate limits, fails over between providers, and
authenticates callers, configured with a single LLM-native YAML file.

## Start here

1. **[Quickstart](getting-started/quickstart/)**: install the binary, connect
   one provider, and send your first request.
2. **[Connect your application](getting-started/connect-your-application/)**:
   point the OpenAI or Anthropic SDK at the proxy.
3. **[Manage configured virtual keys](authentication/managing-secrets/)**:
   create keys and grant each tenant access to models.
