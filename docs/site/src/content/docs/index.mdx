A high-performance proxy for LLM inference APIs. It meters tokens, enforces
token-based rate limits, fails over between providers, and authenticates
callers -- configured with a single, LLM-native YAML file.

This site is being built out section by section. The sections below will
fill in as their content lands:

- **[Getting started](/getting-started/introduction/)**: install the binary,
  validate a config, and serve your first request.
- **[Configuration](/configuration/configuration-file/)**: the field-by-field
  reference for the config format.
- Providers and routing
- API compatibility
- Authentication
- Limits and budgets
- **[Observability](/observability/metrics-and-stats/)**: access logs and the
  `/stats`/`/stats/prometheus` admin endpoints.
- **[Operations](/operations/config-reload/)**: reloading config and draining
  connections on shutdown.
- **[Reference](/reference/cli/)**: the full CLI.
